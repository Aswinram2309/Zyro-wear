==================================================
BEFORE STARTING DEVELOPMENT
==================================================

Do not immediately start writing UI code.

First inspect the project directory and locate:

- ZYRO_Wear_Studio_Imgs/
- logo and review/
- Website Refrance/

Create an internal understanding of:
- Available products
- Product image mappings
- Logo assets
- Review assets
- Website visual references

Then begin development.

Do not ask the developer to manually recreate assets that already exist in these folders.
